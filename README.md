# F-commerce Growth AI

An AI-Powered Order Management and Business Analytics System for Social Commerce Sellers in Bangladesh.

## Project Overview
This system helps Facebook and Instagram sellers manage customer orders, track sales, and analyze business performance.

## Main Features
- Bangla and Banglish message-based order extraction
- Missing order information detection
- Duplicate order warning
- Order management and status tracking
- Sales and business analytics
- Basic income and expense management

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: MySQL
- AI: Python, Pandas, Scikit-learn
- Version Control: Git and GitHub
